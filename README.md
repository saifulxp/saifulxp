# Saiful Islam Portfolio — Full Website

This package contains the complete portfolio website, including Home, About, Work, Contact, 10 project case-study pages, shared CSS/JavaScript, and the original assets folder structure.

## Run locally
Open `index.html` in a browser. For best results, run the folder through a local web server.

## Work filters
The Work page filter labels are: All, Branding & design, and Corporate office. All 10 existing projects are assigned to Branding & design. Corporate office is kept empty for future projects. The Branding and Digital filter buttons have been removed.

## Assets
Keep the `assets` folder in place. It contains the homepage hero image, footer profile image, Work thumbnails, About images, and individual project case-study images.


Client-name note: Project pages use distinct American-style personal names as placeholder/demo client labels. Replace them with the actual client names before presenting these projects as commissioned work.
